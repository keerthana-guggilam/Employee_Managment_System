Employee Management System
Spring Boot | Java | REST API | Spring Data JPA

The Employee Management System (EMS) is a Spring Boot–based backend application designed to manage employee information in an organization. It provides RESTful APIs to create, update, delete, and retrieve employee details without any frontend interface. This project follows a layered architecture to ensure clean code structure and maintainability.

Features:
Add New Employee
Update Employee Details (mobile number, email, department, address, etc.)
Delete Employee using email or ID
Fetch Employee Details by ID or email
Fetch All Employees
Validations for email, mobile number, and blank fields
Exception Handling for invalid or missing data
